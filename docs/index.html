Module cbtools

Procedural rendering, UI, and data helpers for Newt.

Requires Lua 5.1/LuaJIT and the Newt host APIs. Rendering and UI state belong to these tools rather than gameplay.

Usage:

    local cb = require("cbtools")
cb.res.initialise(384, 216)
cb.imgui.button(1, 10, 10, 100, 24)
